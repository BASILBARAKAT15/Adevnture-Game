# Adventure Game

A text-based adventure game developed in Python. Players make choices to navigate through a story, encountering different challenges and outcomes.

## Project Overview

This project is a simple command-line adventure game. Players interact with the game by choosing options that affect the storyline. It demonstrates basic Python concepts such as:

- User input
- Conditional statements
- Loops
- Functions

## Features

- **Interactive Storyline**: Make decisions that impact the game.
- **Multiple Endings**: Replay to explore different outcomes.
- **Command-Line Interface**: Simple and easy-to-use text interface.
